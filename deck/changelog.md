## 2026-05-04 — HARD RULE added: brand assessment before CSS

Added Phase 1R "HARD RULE — never inherit a previous deck's chassis"
section + Phase 3P brand-assessment gate. Triggered by KCH v1 incident
where DGDA cream + heritage gold bled into a hospital-clinical client
deck. Rule requires explicit written assessment of client's primary
identity colour, secondary surface, accent, light/dark dominance, and
banned colours from prior decks BEFORE any CSS is written. Companion
durable memory: feedback_no_cream_default_chassis.md.
