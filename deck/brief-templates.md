# Brief Templates — Pre-Filled Proposal Intakes

When the user's opening message matches one of these scenarios, pre-fill the known fields and only ask for the remaining ones. This cuts intake from 10 questions down to 3-4.

## How to Match

| Opening signal | Template |
|----------------|----------|
| "event", "activation", "festival", "booth", "Soundstorm", "Ramadan" | **Event Activation** |
| "strategy", "pitch", "full pitch", "agency pitch", "capabilities" | **Strategy Pitch** |
| "retail", "permanent", "store", "clinic", "hospital", "hotel", "lobby" | **Retail / Permanent** |
| None of the above, or ambiguous | Ask all 10 as normal |

When a template matches, tell the user: "This sounds like a [template type]. I've pre-filled the usual defaults. Just need a few things from you:" — then ask only the remaining fields.

## Template 1: Event Activation

**Pre-filled:**
- Platform type: FRXME screen activation (primary), with optional social AR extensions
- Budget tier: Growth (~$35K) unless specified
- Pricing: Full pricing (events have clear budgets)
- Key pain points: Standing out in a crowded event space, driving foot traffic to the booth, creating shareable moments that extend reach beyond the event floor
- Parent brand: FRXME (pure activation play)

**Ask the user:**
1. Brand name + website URL
2. Which event / dates / location?
3. Brain dump (meeting notes, goals, audience, vibes)
4. Any ideas or directions already? Reference videos?

**Voice calibration:** Bold, energetic, action-oriented. Events are exciting. The copy should match that energy.

## Template 2: Strategy Pitch

**Pre-filled:**
- Platform type: Mixed (FRXME + social AR + experiential)
- Budget tier: "Not sure yet" (first-touch, don't lead with money)
- Pricing: No pricing, no scoping (get them excited first)
- Parent brand: SHXFT (strategy-led, broader than just FRXME)

**Ask the user:**
1. Brand name + website URL
2. Industry / vertical
3. Brain dump (meeting context, what sparked this, client goals)
4. Any ideas or creative directions? What platforms interest them?
5. Client history (worked with them before?)

**Voice calibration:** Strategic, confident, insightful. Show you understand their business before showing the product.

---

## Template 3: Retail / Permanent Deployment

**Pre-filled:**
- Platform type: FRXME screen (permanent installation)
- Budget tier: Enterprise (~$75K+, multi-unit, long-term)
- Pricing: Scoping only (show what's included, no dollar amounts until site survey)
- Key pain points: Modernizing the physical space, driving engagement in-store, collecting data on foot traffic and customer behaviour
- Parent brand: FRXME (hardware deployment)

**Ask the user:**
1. Brand name + website URL
2. Location type (retail store, clinic, hotel lobby, etc.) + how many locations?
3. Brain dump (what problem they're trying to solve, who visits, current experience gaps)
4. Any ideas for what the screen experience should do?

**Voice calibration:** Professional, solution-oriented. These are enterprise decisions. Keep it polished and ROI-focused.

## Voice Calibration Reference

The `voice` field shapes copy tone across the entire deck. Apply it to:
- Slide headlines and body copy
- Concept descriptions and "How It Works" steps
- CTA language and closing slide tone

| Voice | Characteristics | Example headline |
|-------|----------------|------------------|
| Bold / energetic | Short punchy sentences. Active verbs. Exclamation-worthy. | "Your booth. Their phones. Millions of impressions." |
| Strategic / confident | Longer, considered phrases. Data-driven. Authority. | "Three platforms. One cohesive brand experience." |
| Professional / solution-oriented | Clear, direct. Benefits over features. ROI language. | "Transform every visit into a data-rich brand interaction." |
| Warm / human | Conversational. Empathetic. Story-driven. | "Your patients already trust you. Now surprise them." |
| Corporate / formal | Measured. Precise. Structured. | "A comprehensive digital activation framework for Q4 2026." |
