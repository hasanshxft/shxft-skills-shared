# Prompt: rewrite tighter

Use when copy is *technically fine* but overexplained, hedged, or padded.

---

## The rewrite brief

You are a senior copy chief. The passage below has the right argument but the wrong shape. Tighten it against the following rules, in order:

**1. Cut every third sentence.** Read the result. If the meaning survives, keep the cut. Most drafts survive.

**2. Vary sentence length.** Sentences should burst: short-short-long-short-short. Count words per sentence in the source. If most cluster within ±20% of one length, break the pattern. Cut a sentence in half. Combine two into one. Alternate.

**3. Replace 60%+ of adjectives with the verb they were decorating.**
- "Robust analytics" → "Analytics that hold up."
- "Seamless integration" → "Plugs in. No engineering ticket."
- "Compelling story" → "A story you'd tell at dinner."

**4. Delete every hedge.** Then check if the claim survives. If it does, ship without hedges. If it doesn't, the claim needed evidence, not softening. Add the evidence or drop the claim.

Hedges to purge: typically, generally, often, may, might, some argue, tends to, usually, quite, rather, arguably, perhaps, potentially, kind of, sort of, a bit, essentially, basically, actually.

**5. Delete throat-clearing openers.** Every paragraph should start with the noun, verb, or number that carries the point.

Remove: "In today's landscape," "In a world where," "Now imagine," "Simply put," "Let's dive into," "Whether you're X or Y," "When it comes to," "It goes without saying."

**6. Delete reader-narration.** Do not tell the reader what you just told them. Do not summarise. Do not say "the takeaway is."

Remove: "The result?" "The takeaway?" "The bottom line?" "In other words," "Put simply," "What this means for you is…"

**7. Every claim needs one specific.** If you say "significant impact," name the number. If you say "many brands," name three. If you say "growing category," give the CAGR.

Vague → specific:
- "significant impact" → "27% uplift"
- "many brands" → "Nike, Adidas, Gymshark"
- "recent growth" → "3.4× since 2023"

**8. Read the final version aloud.** If you stumble even once, that seam is where the rewrite failed. Fix it.

---

## Delivery format

Return two versions:

### Version A — tightest possible cut
The minimum viable version of the argument. What survives if you're brutal about rule 1 (cut every third sentence).

### Version B — clean pass with all rules
Applied all eight rules. Slightly longer than A. This is the shippable version 90% of the time.

Then note in one line what changed structurally between the original and B (word count, sentence count, biggest cut). No essay — one line.

---

## When NOT to use this prompt

- Copy that's fundamentally in the wrong voice. Use `rewrite-in-voice.md` instead.
- Copy that reads AI-generated. Use `rewrite-de-tell.md` instead.
- Copy that's too short and needs texture added. This prompt only cuts.
